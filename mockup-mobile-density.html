Decision 12’s parked caveat. --accent and --destructive are the same value in every theme (style.css:36/41), and the custom theme sets --destructive: var(--accent) outright. It has always been true — the FAB has always been accent — but 14B filled more controls with accent, so the collision is easier to meet: the button that creates and the button that destroys are the same red, sometimes on the same screen. Below: the collision, and the smallest fix that keeps a custom accent working.
